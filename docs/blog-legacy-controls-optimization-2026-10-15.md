# 博客旧控件优化方案

日期：2026-10-15。状态：优化阶段已在本地实施；未提交或部署。新建中的博客文章由用户撰写，本轮不检查或修改。鲸鱼娘已作为上一轮独立发布。

## 推荐方向

保留文章排版与黑白基调，蓝色仅用于鲸鱼娘和少量选中状态。桌面左下看板娘、右下音乐与返回顶部；手机保留小型入口，打开时使用底部面板。阅读区域保持稳定，不因播放或切歌跳动。

相比直接复制旧工作树整个改版，推荐分阶段迁入并重新审查。单纯换皮无法解决状态和生命周期问题；整套替换则容易把音乐、看板娘和其他工作区改动一起带入。

## 实施边界与文件

1. 第一阶段（本地实施）：修改 technical/source/_data/body-end.swig、technical/source/music/index.md，新增 technical/source/js/music/player.js、ui.js、cover-loader.js、music.css 和默认封面。音频单例、PJAX 页面订阅、封面竞态、失败重试和现有看板娘 ducking 接口已落实。前一阶段 Hexo 构建和播放器模块语法检查曾通过；本轮后续改动仅做静态检查与 JavaScript 语法检查，没有重新构建或运行浏览器回归。
2. 第二阶段（本地实施）：播放器 CSS 统一 44px 触摸目标、键盘焦点、手机安全区、暗色模式与减少动态效果；播放器面板、迷你控件、看板娘和鼠标画布采用明确的层级。移除音乐状态驱动返回顶部唱片旋转的旧 CSS。
3. 第三阶段（接口已具备）：播放器提供 setCompanionDucking(active)，语音控制器可调用；默认音量和压低系数分开计算。鲸鱼娘没有配套语音，因此没有播放真实声音，也未验证实际 duck/restore。
4. 第四阶段（本地实施）：鼠标拖尾只在桌面、前台、未减少动态效果时绘制；光标静止时没有持续动画循环；开关在鲸鱼娘设置中并按设备记忆。清理前检索全仓引用后，删除旧 Cubism 2 模型 111 个文件（20,093,401 bytes）、live2d-config.json 与 model_list.json；保留提及旧路径的历史文章与检查工具。

工作区存在一个用户正在撰写的新文章；本轮没有打开、读取、修改或纳入提交。

## 验收标准

- 首页→音乐页→文章→音乐页连续往返，音频始终一个实例，当前页面时间/标题/播放状态同步，监听数不随往返增长。
- 快速切换三首、封面慢响应/404、音频拒绝播放，分别验证当前封面正确、默认图可用、错误可恢复。
- 暂停页面首屏不请求音频，播放后按需加载；切页不无故自动播放。
- 键盘及触摸可操作所有控件；Escape 关闭后焦点返回；320px 手机宽度无横向溢出，横屏/安全区不遮挡正文关键操作。
- 语音联动使用实际可播放样本验证压低/恢复与竞态；fixture 仅作为逻辑证据。
- 后台和减少动态效果时无持续看板娘/拖尾循环，恢复前台不创建重复实例。
