- 圆润紧凑的 Q 版比例；蓝眼、深蓝长卷发，发梢较克制的浅蓝渐变，弯曲呆毛。

- 深蓝腰带，两列各两颗金扣；白色褶边围裙及深蓝喷水小鲸鱼图案。
- 深蓝蓬裙、细金色藤纹和小蝴蝶结、白色衬裙褶边。
- 白色短褶袜、深蓝圆头 Mary Jane 鞋；深蓝鲸尾向背后侧方弯曲。
