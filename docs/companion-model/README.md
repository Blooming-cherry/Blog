## 分层动作实现（2026-10-15）

运行：在本目录执行 `node serve-preview.cjs`，浏览器打开 http://127.0.0.1:8765/ 。服务仅监听本机，Ctrl+C 停止。

上一版整图 WebGL 网格变形已被用户否决，并从当前预览代码中移除。当前使用 21 个独立裁切 PNG，按照 `rig.json` 的层级、原坐标和关节支点绘制；不再使用液化着色器。源图像素拆分是确定性的，不生成另一套角色。

- `layers/`：头、左右后发、中央刘海、呆毛、左右鲸鳍耳、眼白/眼睑、独立瞳孔、口型、躯干、双臂、袖口与手、裙摆、双腿和鲸尾。源切块之外另有 21 个小范围补缝 PNG。
- `blue-maid-05-layered-v1.psd`：21 个源图层，以及默认隐藏的 21 层接缝补量组。
- `rig.json`：图层文件、裁切坐标、父子关节、支点和动作时长。
- `layers-overview.png`：拆层总览。
- `motion-preview.html` / `motion-preview.js`：Canvas 2D 图层装配；呼吸、独立发束/鲸尾轻摆、眨眼、头与瞳孔跟随、点头、挥手、开心回应；提供静态还原、图层展开/显隐和关节定格滑杆。

## 验证与复建

1. `node build-layers.cjs` 依原坐标轮廓拆层，重新读取导出的 PNG 拼回原图；714,312 个可见像素的 RGBA 通道差异为 0。记录为 `layers/reconstruction-check.json`。这只证明像素与坐标未丢失，不证明轮廓拆分或遮挡补绘已达到正式模型美术质量。
2. `node export-psd.cjs` 导出后重新读取 PSD，检查源图层的名称、坐标和 RGBA，差异为 0。记录为 `layers/psd-check.json`。尚未在 Photoshop 或 Cubism Editor 中进行导入验收。
3. `node review-layers.cjs` 生成轮廓定位网格与拆层总览。
4. 本机浏览器实际检查了静态装配、拆层展开、关闭鲸尾层、闭眼定格、手臂 -6 度和鲸尾 4 度定格；渲染成功，错误日志为空。JavaScript 语法检查通过。后台暂停和减少动态效果有实现，未在本轮自动化验证。

构建使用本机 bundled sharp（可通过 BLOG_SHARP_MODULE 指定模块路径）；PSD 导出器使用本目录 tools 的 ag-psd，可用 `npm ci --prefix tools` 复建依赖。PSD 工具文档：https://github.com/Agamnentzar/ag-psd 。工具依赖不进入博客运行时。

## 尚未完成

当前为初版二维分层装配。补缝主要是 10 像素范围的边缘颜色延展，以及眼眶皮肤/眼白底层；不等同于完整隐藏肢体与衣物补绘。大角度转头、抬臂仍需精修遮挡区域与拆层边界。眨眼是独立眼层压缩配合闭眼线条，还没有 Cubism 眼睑网格与插值。眉毛没有单独拆分。当前 PNG/PSD 不能直接视为完成绑定的 Live2D 模型；尚无新 CMO3、物理绑定、MOC3 或线上接入。
