### 1. $\mathrm{open}$ 与 $\mathrm{random.shuffle}$ ，获取文件

首先准备训练语料。这份脚本约定从 input.txt 中逐行读取文本，每个非空行作为一个文档；默认数据是一行一个姓名。程序去掉每行首尾的空白，过滤空行，再随机打乱文档顺序。

这里没有专门解析 CSV、Markdown 或 JSON。它们本身也可以是文本文件，但直接交给这段代码时，字段名、逗号和格式标记也会被当作普通字符读取。因此，如果只想训练其中的正文，就需要先提取并整理文本。

```python
if not os.path.exists('input.txt'):
    import urllib.request

    names_url = 'https://raw.githubusercontent.com/karpathy/makemore/988aa59/names.txt'
    urllib.request.urlretrieve(names_url, 'input.txt')

docs = [line.strip() for line in open('input.txt') if line.strip()]
random.shuffle(docs)
print(f"num docs: {len(docs)}")
```

### 2. $\mathrm{sorted}$ 与 $\mathrm{set}$ ，字符编号

文本读进来以后，还不能直接进入矩阵运算。这份脚本先收集语料中的不同字符，为每个字符分配一个整数编号；之后再根据编号查找它的嵌入向量。编号只是区分字符的标记，本身没有大小或语义关系。

```python
uchars = sorted(set(''.join(docs)))
BOS = len(uchars)
vocab_size = len(uchars) + 1
```

uchars 保存排序后的字符表，字符在表中的索引就是编号。BOS 使用一个额外编号，在这份实现中同时表示文档开始和结束。这样，后面创建嵌入矩阵时，vocab_size 就有了明确的来源：普通字符数量，再加一个特殊符号。

### 3. $\mathrm{Value}$ ，创建计算图节点

在一次训练中，我们需要知道：每个权重发生一点变化，最终损失会怎样变化。这个变化率就是损失对该权重的偏导数，按权重顺序排列起来，就组成了梯度。为了通过链式法则计算它，程序需要保存参与计算的节点、节点之间的依赖，以及每次运算的局部导数。

因此，作者定义了 Value 类，让一个数同时携带自己的计算来路。这里仍然使用 math 计算对数、指数等数值；Value 额外记录求导信息，再由 backward() 沿计算图反向累加梯度。学习率则在得到梯度之后，参与权重更新。

```python
# 仅展示结构，方法的具体实现以 ... 省略。
class Value:
    # 让 Value 携带求导路径
    __slots__ = ('data', 'grad', '_children', '_local_grads')

    def __init__(self, data, children=(), local_grads=()):
        ...

    # 运算符重载
    def __add__(self, other):
        ...

    # 沿反向顺序传播梯度
    def backward(self):
        ...
```

### 4. $\mathrm{matrix}$ ，初始化与创建参数

```python
n_layer = 1  # 神经网络深度（网络层数）
n_embd = 16  # 神经网络广度（向量维数）

# 注意力窗口：当前能够访问的 token 数量。
# 这里不断累积当前段的全部前缀，由 block_size = 16 限制处理长度。
# 它没有删除最早的缓存来实现滑动窗口。
block_size = 16

n_head = 4  # 注意力头
head_dim = n_embd // n_head  # 用广度除以注意力头数量，得到头向量的维度

matrix = lambda nout, nin, std=0.08: [
    [Value(random.gauss(0, std)) for _ in range(nin)]
    for _ in range(nout)
]

state_dict = {
    'wte': matrix(vocab_size, n_embd),
    'wpe': matrix(block_size, n_embd),
    'lm_head': matrix(vocab_size, n_embd),
}

for i in range(n_layer):
    state_dict[f'layer{i}.attn_wq'] = matrix(n_embd, n_embd)
    state_dict[f'layer{i}.attn_wk'] = matrix(n_embd, n_embd)
    state_dict[f'layer{i}.attn_wv'] = matrix(n_embd, n_embd)
    state_dict[f'layer{i}.attn_wo'] = matrix(n_embd, n_embd)
    state_dict[f'layer{i}.mlp_fc1'] = matrix(4 * n_embd, n_embd)
    state_dict[f'layer{i}.mlp_fc2'] = matrix(n_embd, 4 * n_embd)

# 将 params 平展成一个列表
params = [p for mat in state_dict.values() for row in mat for p in row]
print(f"num params: {len(params)}")
```
这一段先给模型建好权重。字符和位置各有一张表，注意力和前馈子层各有自己的矩阵，最后给字符打分还要用一张输出矩阵。这里说的前馈子层，就是 $Transformer$ 每层里接在注意力后面的那个前馈网络（$\mathrm{FFN}$）。

matrix(nout, nin) 建立 nout 行、每行 nin 个 Value 的权重矩阵，每个数来自均值 0、标准差 std 的高斯抽样。这里维度为 16，4 个注意力头各占 4 维。权重名字由 `state_dict` 统一管理。

在学习中，我更关注其中与我接触的C++算法不同的一些、或者类而不同的函数处理方式——例如 lambda 函数。以下经过自动换行，实际只有一行：

```python
matrix = lambda nout, nin, std=0.08: [
    [Value(random.gauss(0, std)) for _ in range(nin)]
    for _ in range(nout)
]
```

初学 lambda，加上与 "[表达式 for 变量 in 可迭代对象]"  嵌套运用结合，确实难以理解。lambda 冒号前是参数，冒号后的表达式结果会自动作为返回值。**矩阵的形状由列表嵌套和循环次数决定。** ——内层循环 nin 次，得到一行的 nin 个元素。外层循环 nout 次，得到 nout 行。元素按生成顺序加入列表，下标随位置自然确定，之后可以用 w[i][j] 取第 i 行、第 j 列。range 的默认步长是 1，这里的行列数量来自循环次数。定义这一行时，函数体还没有执行。

为了便于理解我将一份双层迭代的代码贴在下面，其中由于我们在此函数运算过程中不关心下标，所以我们可以用 `_` 代替我们常用的 i 、j、 k：

```python
def matrix(nout, nin, std=0.08):
    rows = []
    for _ in range(nout):
        row = []
        for _ in range(nin):
            row.append(Value(random.gauss(0, std)))
        rows.append(row)
    return rows
```

对于下面的矩阵我们作出以下分类：

|每层的矩阵|当前形状|用途|
|---|---|---|
|`attn_wq`| 16 × 16 |生成查询向量|
|`attn_wk`| 16 × 16 |生成键向量|
|`attn_wv`| 16 × 16 |生成值向量|
|`attn_wo`| 16 × 16 |混合多个注意力头拼接后的结果|
|`mlp_fc1`| 64 × 16 |把输入映射成 64 个隐藏分量|
|`mlp_fc2`| 16 × 64 |把隐藏分量组合成 16 维输出|

以上分类帮我们理解了矩阵中不同变量的实际意义，并且完成了权重矩阵的初始化，以下我们将演示该矩阵在整个前向计算中的运算过程。

### 5. $\mathrm{linear}$ ，矩阵与向量计算

前面那些矩阵建立起来以后，给它一个向量，具体怎么算？下面是 linear 函数的定义。

```python
def linear(x, w):
    return [
        sum(wi * xi for wi, xi in zip(wo, x))
        for wo in w
    ]
```

这里又出现了列表表达式，外层的 for wo in w 逐行取出权重矩阵，每取出一行，就让它和输入向量 x 做一次点积。zip(wo, x) 把这一行的权重与输入分量按位置配对，逐项相乘，再通过 sum 相加。每一行得到一个数，所有行的结果组成输出向量。

例如，输入向量有两个分量，权重矩阵有三行两列：

$$
x= \begin{bmatrix} 2\\ 3 \end{bmatrix}, \qquad W= \begin{bmatrix} 1&0\\ 0&1\\ 1&1 \end{bmatrix}
$$

第一行算出 $1\times2+0\times3=2$，第二行算出 $0\times2+1\times3=3$，第三行算出 $1\times2+1\times3=5$，最终得到：

$$
Wx= \begin{bmatrix} 2\\ 3\\ 5 \end{bmatrix}
$$

这也让前文中的 matrix(nout, nin) 有了具体含义：每行需要 nin 个权重，与输入的 nin 个分量配对；一共有 nout 行，因此输出有 nout 个分量。对应前馈网络的 fc1，就是让同一个 16 维向量与 64 行权重分别计算，得到 64 个结果。

### 6. $\mathrm{Softmax}$ 与 $\mathrm{RMSNorm}$ ，调整数值尺度

先找 logits 中最大的普通数值 max_val；每一项减去它，求指数；把所有指数相加；最后各项除以总和，得到词表概率或注意力权重。减最大值用于改善数值稳定性；它不会改变这组 $Softmax$ 的数学结果。

$Softmax$ 做的事情通常叫**把分数转换为概率分布**，也称为**概率归一化**。它本身常被称为 $Softmax$ 函数或 $Softmax$ 激活函数。

它先对每个输入分数取指数，再除以所有指数值的总和：

$$
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

这样得到的每个值都大于 0，所有值相加等于 1。分数越高，对应的概率越大。

$RMSNorm$ 用来**调整向量的整体尺度**。从统计学看，它根据一组数的均方根进行缩放。在机器学习中，它属于**归一化层**，帮助网络在计算时控制中间数值的大小。

对于一个有 $n$ 个分量的向量，它先计算均方根 $RMS$：

$$
\mathrm{RMS}(x)=\sqrt{\frac{1}{n}\sum_{i=1}^{n}x_i^2}
$$

平方让正负数都贡献到大小的度量中，取平均消除分量数量的直接影响，再开平方恢复原来的量纲。它可以描述这组数**相对于零的整体大小**。

从统计学上，还可以把均方根与均值、方差联系起来。使用除以 $n$ 的方差定义时：

$$
\mathrm{RMS}(x)^2=\operatorname{Var}(x)+\bar{x}^{\,2}
$$

对应到源码，ms 就是各分量平方后的平均值，统计学上叫这组分量的**二阶原点矩**。scale 取 ms 加上 0.00001 后的平方根倒数，加这个小量可以避免全零向量导致除零。

因此，均方根同时受**波动程度和整体均值**影响。$RMSNorm$ 只调整尺度，处理后的向量仍然可以有非零均值。你在统计学中学过的“减均值、除以标准差”的标准化，则还包含居中操作。

与前面讨论的 $Softmax$ 对照，$Softmax$ 把分数转成总和为 1 的概率或权重；$RMSNorm$ 把表示向量缩放到均方根约为 1，保留正负号及分量比例。

### 7. $\mathrm{gpt}$ ，单个位置的前向计算

```python
def gpt(token_id, pos_id, keys, values):
    ...
```

以下几段都在 gpt 函数体内。token_id 是当前字符的编号，pos_id 是当前位置，keys 和 values 存着各层已经计算过的键和值。

#### 7.1 查表、 $\mathrm{zip}$ 与 $\mathrm{RMSNorm}$ ，准备输入

回到前面那张图，假设我们要学的姓名是 anna。我把两个 n 分别写成 n₁ 和 n₂，方便指着其中一个说话。字符表里仍然只有一个 n。算上开头的 $BOS$，第一个 a 在位置 1，两个 n 分别在位置 2 和 3。

```python
tok_emb = state_dict['wte'][token_id]
pos_emb = state_dict['wpe'][pos_id]
x = [t + p for t, p in zip(tok_emb, pos_emb)]
x = rmsnorm(x)
```

试着把手指从第一个 n 移到第二个 n。查 wte 时，两次取的都是 n 对应的那一行。查 wpe 时，手指往右移一格，行号就从 2 变成了 3。这两张表都是第 4 节建好的权重矩阵，表里的数会随训练更新。

第三行的 zip 把两行里下标相同的数配在一起相加。字符向量有 16 项，位置向量也有 16 项，加完还是 16 项。这就是 gpt 开头交给 $RMSNorm$ 的 x。

#### 7.2 $\mathrm{linear}$ 、 $\mathrm{Softmax}$ 与 $\mathrm{extend}$ ，多头注意力

进入这一层，作者先用 `x_residual = x` 留住输入，再把 x 归一化，用三组不同的矩阵分别做一次 linear，得到 q、k、v。它们分别叫**查询向量、键向量和值向量**。我看这段时会先把 v 遮住。只看 q 和 k，就能给各个位置打分。至于一个位置到底传来什么数，再去看它的 v。

```python
keys[li].append(k)
values[li].append(v)
```

这两行放在比较之前，顺序很有意思。走到第二个 n 时，本层已经依次存了 $BOS$、a、第一个 n、第二个 n 的键和值，当前字符也能参与计算。姓名末尾的 a 此时还没有传进 gpt。

那么“四个头”又是怎么回事？前面算过 `head_dim = 16 // 4`，每个头分到 4 个分量。循环里的 h 从 0 数到 3。假如 h 等于 1，起点 hs 就等于 4，下面第一行实际取的是 `q[4:8]`，也就是下标 4、5、6、7。对存下来的每一个 k 和 v，也都取同一段。

```python
q_h = q[hs:hs+head_dim]
k_h = [ki[hs:hs+head_dim] for ki in keys[li]]
v_h = [vi[hs:hs+head_dim] for vi in values[li]]
```

这里恰好有两个 4，容易看岔。一个是**这个头的向量有 4 个分量**，另一个是**走到第二个 n 时已经有 4 个位置**。算分数时，`q_h` 和一个位置的键做点积，把 4 个分量的乘积相加，再除以头维度的平方根，也就是 2，得到这个位置的一个分数。换下一个位置再算一次。把 4 个位置的分数交给 $Softmax$，就得到了这个头对各位置的权重。

值向量怎么用？只看它的第一项。假设四个位置的权重依次是 0.1、0.2、0.3、0.4，而四个值向量的第一项依次是 1、0、2、3。这个头输出的第一项就是 $0.1×1+0.2×0+0.3×2+0.4×3=1.9$。剩余三项各取自己那一列，沿用同一组权重。这里的数字只是为了方便手算。

现在再看 `x_attn.extend(head_out)`。每个头算出 4 个数，extend 逐个放进去，四个头凑成一个长度为 16 的列表。若在这里用 append，里面会放着四个小列表，下一行 linear 要用的却是可以逐项做点积的 16 个数。拼好后经过 `attn_wo` 再混合一次，与本节开头留下的输入逐项相加，这就是图上的第一次**残差相加**。

#### 7.3 $\mathrm{linear}$ 与 $\mathrm{relu}$ ，前馈子层

第 4 节表格里还有两张长方形的矩阵没有细看。进前馈子层时，当前位置的 x 已经带上了从前面各个位置取来的信息。后面这六行都可以只盯着当前位置看。

```python
x_residual = x
x = rmsnorm(x)
x = linear(x, state_dict[f'layer{li}.mlp_fc1'])
x = [xi.relu() for xi in x]
x = linear(x, state_dict[f'layer{li}.mlp_fc2'])
x = [a + b for a, b in zip(x, x_residual)]
```

fc1 有 64 行，每行与这 16 个输入分量做一次点积，得到 64 个数。中间的 $ReLU$ 逐项取 $\max(0,x)$，比如相邻两项是 −2 和 3，经过这一行就变成 0 和 3。如果去掉 $ReLU$，这两张矩阵连乘可以合成一张。现在多了这一步，哪些分量能传给 fc2，还得看这次输入算出来的正负。fc2 再把 64 项组合为 16 项，恰好能与留下来的 16 项逐一相加。这里留住的是**刚刚经过注意力和第一次残差相加的 x**。看图时可以分别点一下两条旁路，对照这两次 `x_residual = x`。

#### 7.4 $\mathrm{linear}$ ，输出字符分数

读到 gpt 的最后，只剩下一次 `linear(x, state_dict['lm_head'])`。这张矩阵的每一行对应词表里的一个候选符号，出来的一串分数叫 $\mathrm{logits}$。刚才注意力里的 $Softmax$ 是在**已经看过的位置**之间分配权重。接下来训练代码还会调一次 $Softmax$，这回参与分配的是**下一个字符的所有候选项**。前面交互图的末页只画了四项，图上的数值是教学算例。图中标作 $EOS$ 的结束项，在脚本里和开头共用 $BOS$ 的编号。

### 8. $\mathrm{gpt}$ 、 $\mathrm{Softmax}$ 与 $\mathrm{log}$ ，计算训练损失

gpt 定义完以后，脚本先设置优化器参数，把 m 和 v 初始化为零，然后进入训练循环。每一步先取一个姓名，把字符转换成编号，在两端加上 $BOS$，再清空本次要用的键和值缓存。

```python
doc = docs[step % len(docs)]
tokens = [BOS] + [uchars.index(ch) for ch in doc] + [BOS]
n = min(block_size, len(tokens) - 1)
keys, values = [[] for _ in range(n_layer)], [[] for _ in range(n_layer)]
```

在训练循环里我更喜欢把 `tokens[pos_id]` 和 `tokens[pos_id + 1]` 并排写。两项从同一个姓名里面取，下标错开一格。

|当前位置|送入 gpt|希望它接着写出|
|---|---|---|
|0|BOS|a|
|1|a|n|
|2|第一个 n|n|
|3|第二个 n|a|
|4|a|BOS|

单看位置 2 和 3 就挺有意思。前一次送进去 n，希望出来的也是 n。后一次送进去的还是 n，答案却换成了 a。

```python
token_id, target_id = tokens[pos_id], tokens[pos_id + 1]
logits = gpt(token_id, pos_id, keys, values)
probs = softmax(logits)
loss_t = -probs[target_id].log()
```

训练时，下一次送进去的字符直接取自原姓名，即使模型刚才猜错了，也还是沿原文往下读。每个位置只取正确答案对应的概率。假如第二个 n 后面，模型给 a 的概率是 0.8，这一步的损失约为 0.22。如果只给了 0.1，损失就约为 2.30。这里用的是自然对数，前面的负号让正确答案的概率越高，损失越小。anna 一共提供五次预测，五个损失取平均，就是这一训练步的 loss。对于更长的文本，脚本每次最多取 `block_size` 个位置。

### 9. $\mathrm{backward}$ ，反向传播

我在这里会回过头去看一眼 Value 的定义。调用 loss.backward() 时，先把损失对它自身的导数设为 1，沿计算图反向走，把每条路径贡献的导数加进相应节点的 grad。比如两个 n 查到的是同一行字符权重，同一个权重在这次计算中用了几回，各处传回来的贡献就会在它身上相加。

### 10. $\mathrm{enumerate}$ 循环与 $Adam$ ，更新参数

作者用了 $Adam$，给 params 中的每个权重配了两个数，m 记梯度的指数移动平均，v 记梯度平方的指数移动平均。越近的训练步，在各自的平均数里占的权重越大。m 里的正负可以抵消，v 里的平方保留了梯度大小的信息。$RMSNorm$ 沿着**同一个向量的各个分量**求均方。$Adam$ 的 v 沿着训练步数累积**同一个权重**的梯度平方。

```python
lr_t = learning_rate * (1 - step / num_steps)
for i, p in enumerate(params):
    m[i] = beta1 * m[i] + (1 - beta1) * p.grad
    v[i] = beta2 * v[i] + (1 - beta2) * p.grad ** 2
    m_hat = m[i] / (1 - beta1 ** (step + 1))
    v_hat = v[i] / (1 - beta2 ** (step + 1))
    p.data -= lr_t * m_hat / (v_hat ** 0.5 + eps_adam)
    p.grad = 0
```

enumerate 每次给出一个下标 i 和对应的参数 p，m[i]、v[i] 就能与这个参数配在一起。算出 m_hat 和 v_hat 时，校正从零开始累积带来的偏差。接下来的减法动到 p.data，也就是下次前向计算会读到的权重数值。假如这里的 `m_hat` 为负，分母为正，减去这一项，权重就会往大的方向走。“下降”说的是希望损失变小，落实到某一个权重，往大、往小都有可能。最后把 p.grad 清零，m 和 v 留给下一步接着用。

脚本把打乱后的姓名按顺序取出，每步读一个姓名、更新一次权重，默认做 1000 步。换姓名时，注意力存下来的键和值也重新置空，否则下一个姓名就会读到上一个姓名的字符。学习率从 0.01 开始，随着步数线性减小。

### 11. $\mathrm{gpt}$ 、 $\mathrm{Softmax}$ 与 $\mathrm{random.choices}$ ，生成姓名

让它自己写一个姓名，手里只给一个起始符号 $BOS$。gpt 还是刚才那个函数，我把它返回之后的两行摘在下面。

```python
probs = softmax([l / temperature for l in logits])
token_id = random.choices(range(vocab_size), weights=[p.data for p in probs])[0]
```

temperature 设为 0.5，除过以后，候选分数之间的差距变成原来的两倍，再经过 $Softmax$，概率会更集中在得分高的字符上。random.choices 按概率抽一个编号，返回一个只装了这次结果的列表，所以末尾还要用 [0] 取出那个编号。这里仍然可能抽到得分第二、第三的字符。

如果这次抽到了 a，程序就把 a 记进姓名，下一次送入 gpt 的也是这个 a。如此接着写，抽到 $BOS$ 就在那个位置收笔，或是达到 16 次预测的上限。外层循环重新从 $BOS$ 起笔，一共尝试生成 20 个姓名。
